# open-browser 工作区、标签组与接管

open-browser 使用 Chromium 原生窗口和标签页。Agent 打开的页面进入左侧的工作区标签组，普通页面保持独立。新标签页只显示正在运行的 Agent、运行历史和复制提示词入口。

## 状态显示

标签组标题使用「Agent 名称 · 任务名」。默认状态按 Agent 稳定配色，人工接管显示绿色，交接中显示黄色，等待凭据、失败和结果待核实显示红色。扩展图标显示当前页面的执行阶段。

macOS 受管页面底部显示原生悬浮栏。Agent 执行时悬浮栏显示当前阶段，用户可以点击 **人工接管**。任务结束后按钮变为 **结束**，点击后服务撤销任务分组并保留用户选中的结果页，不打开额外交付窗口。

## 接管流程

1. 用户从左侧工作区、扩展图标或悬浮栏进入当前页面。
2. 服务撤销工作区的 Agent 控制代次，等待已经派发的输入收束，随后进入人工接管状态。
3. 人工接管期间，Agent 的观察、输入和关闭请求都会被拒绝。用户直接在原标签中完成登录或编辑。
4. 用户点击 **交回 Agent** 后，服务签发新的控制代次。Agent 必须重新观察当前文档，再继续后续步骤。
5. 用户点击 **结束** 后，服务等待在途动作收束，关闭临时标签，保留选中的结果标签并清理任务组。

接管只影响选中的工作区，其他工作区可以继续并发运行。页面导航、文档变化和交接都会使旧元素引用失效。

## 凭据与来源

缺少凭据时，扩展只显示当前页面、来源和凭据引用。用户可以从可信入口补充凭据，服务按工作区和来源保存于内存，Agent 继续使用同一任务。页面来源被阻止时，用户可以在受信面板授予本次任务所需的导航或静态资源权限。
